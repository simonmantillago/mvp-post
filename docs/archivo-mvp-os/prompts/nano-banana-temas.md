# Prompts para Nano Banana — temas Manhattan 2003 y Leopardo & Lirios

Los bocetos de **Bliss** (en `docs/mockups/bliss/`) ya fijan la composición. Para los otros temas no se rediseña nada: se toma cada boceto Bliss y se le **cambia solo la piel** (colores del chrome, wallpaper, pequeños detalles). Así los tres temas quedan con la misma estructura y la app puede cambiar de tema sin moverse nada.

## Cómo usarlos
1. Abre un chat nuevo de Nano Banana por tema.
2. Adjunta **un** boceto de `docs/mockups/bliss/` (empieza por `03-escritorio.webp`, que define el wallpaper).
3. Pega el **bloque del tema** + la **instrucción de pantalla**.
4. Cuando el escritorio te guste, adjunta también esa imagen del escritorio en las pantallas siguientes para que el wallpaper y los colores no cambien.
5. Si algo se mueve de lugar, responde: `keep the exact same layout, positions, texts and photos as the attached image; only change colors and wallpaper`.
6. Guarda en `docs/mockups/manhattan/` y `docs/mockups/leopardo/` con los mismos nombres (`01-carga.png`, `02-bienvenida.png`…).

---

## Instrucción de pantalla (pegar después del bloque del tema)

```
Recreate the attached image exactly: same vertical 9:16 phone screen, same layout, same window, same positions and sizes, same texts in Spanish, same photos and people, same icons and the same small charms. Change ONLY the color theme and the wallpaper as described above. It must still look like a real Windows XP screenshot from 2003, not a modern redesign. Crisp readable text, no phone frame. Do not use the real Microsoft Windows logo; keep the custom four-pane flag logo.
```

## Bloque del tema: Manhattan 2003 (Sex and the City)

```
Theme "Manhattan 2003", inspired by Sex and the City and New York glamour around 2003.
Window chrome and taskbar: like the black Windows XP "Royale Noir" theme — glossy black and charcoal title bars and taskbar with thin soft-gold edges; the Start button is black with a gold border instead of green; selected items get a very soft blush-pink highlight. The pink stays subtle, only as a small accent; gold is the metal of the few tiny rhinestones and charms.
Wallpaper: the Manhattan skyline at night seen from a high window, warm lit windows, the Empire State and Chrysler buildings, a soft mist of city lights, cinematic but photographic, like a 2003 desktop wallpaper.
Boot screen: black background; the four-pane flag logo panes in black glass, pale gold, champagne and one soft blush pane; the "MVP OS" script in pale champagne; the loading blocks in gold.
Welcome screen: the top and bottom bands in deep charcoal black, the middle field in a dark midnight-blue-to-black gradient, divider line in pale gold.
```

## Bloque del tema: Leopardo & Lirios

```
Theme "Leopardo & Lirios", her personal taste: leopard print, lilies, cherries, red roses, baroque gold.
Window chrome and taskbar: the Windows XP Luna shape and gloss kept exactly, but recolored deep wine / oxblood red with antique-gold bevels and edges; the Start button is glossy burgundy with a gold border; selected items get a dusty-rose highlight. Gold is the metal of the few tiny rhinestones and charms (a cherry, a small gold heart).
Wallpaper: a rich photographic collage of leopard print fur with dark wine-red and dusty-pink lilies, glossy dark cherries and deep red roses, a few baroque gold ornaments, dark and moody, like a 2000s glam desktop wallpaper. Keep the area behind desktop icons and windows calm enough so text stays readable.
Boot screen: black background; the four-pane flag logo panes in wine red, antique gold, leopard print and one dusty-rose pane; the "MVP OS" script in antique gold; the loading blocks in burgundy-gold.
Welcome screen: the top and bottom bands in deep oxblood, the middle field a dark wine gradient with a very faint leopard texture, divider line in antique gold.
```

## Extra: solo el wallpaper (para usarlo como imagen real en la app)

Cuando tengas el escritorio de un tema que te guste, pide el fondo limpio en alta resolución:

```
Generate only the wallpaper from the attached image, with no icons, no windows, no taskbar and no text: a clean vertical 9:16 image at the highest resolution, same scene, same colors and lighting.
```

Guárdalo como `docs/mockups/<tema>/wallpaper.png`. Lo mismo vale para el de Bliss si quieres uno sin íconos.
