# Archivo: MVP OS (dirección descartada)

Hasta el 2026-10-23 la app era "MVP OS", un sistema operativo estilo Windows XP con tres temas (Bliss Rosa, Manhattan 2003, Leopardo & Lirios). El 2026-10-24 el usuario cambió la dirección a **The MVP Post** (periódico). Nada de esta carpeta es referencia para el diseño actual; se guarda solo como historial.

- `mockups/`: bocetos de Nano Banana de MVP OS.
- `prompts/`: prompts de esos bocetos.
- `inspiration/`: referencias XP, Manhattan y Leopardo & Lirios.
- `contrato-direccion-xp.md`: contrato de dirección de Impeccable ("Pedrería OS"), sacado de `.impeccable/surfaces/`.
